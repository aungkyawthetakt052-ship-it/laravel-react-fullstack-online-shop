# Laravel + React Full Stack Application

A modern full-stack web application built with **Laravel** (backend) and **React** (frontend).  
Features a responsive dashboard, SweetAlert2 confirmation dialogs for delete actions, and full dark mode support.

---

## Features

- **Dashboard** – Clean and modern admin dashboard with key metrics and overview cards
- **CRUD Operations** – Create, Read, Update, Delete functionality
- **SweetAlert2 Delete Confirmation** – Beautiful confirmation dialogs before deleting records
- **Responsive Design** – Fully responsive layout (Desktop, Tablet, Mobile)
- **Dark Mode Support** – Toggle between Light and Dark themes with persistent preference
- **Modern UI** – Built with Tailwind CSS
- **Authentication** – Laravel Breeze / Sanctum ready
- **API-based Architecture** – Laravel API + React SPA

---

## Tech Stack

### Backend
- Laravel 11

### Frontend
- React 18
- Vite
- Tailwind CSS
- SweetAlert2
- Axios
